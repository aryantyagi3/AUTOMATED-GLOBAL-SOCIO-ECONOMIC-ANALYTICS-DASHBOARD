# PROJECT OVERVIEW
*OBJECTIVE*
Build an automated, live Power BI dashboard to track and analyze global health, economic, and social development indicators.

*DATA ARCHITECTURE*
• Extraction & ETL: A Python script automatically fetches real-time data from a public API and cleans it for analysis, eliminating manual downloads.
• Live Integration: Direct connection between Python and Power BI enables automatic dashboard refreshes whenever new data becomes available.

*KEY ANALYTICAL FOCUS AREAS*
• Macroeconomic Baseline: Evaluates average GDP per capita, GDP growth rate, trade value, health expenditure (% of GDP), and forest area proportions.
• Regional & Longitudinal Trends: Compares health spending across world regions and tracks historical shifts in digital connectivity (mobile/internet subscriptions), renewable energy use, and unemployment.
• Digital Impact: Assesses correlations between internet penetration, immunization awareness, and unemployment reduction.
• Poverty Benchmarking: Identifies the top 10 and bottom 10 countries in poverty reduction progress to highlight policy successes and intervention needs.
• Health Correlations: Examines interrelationships among health expenditure, life expectancy, immunization rates, child mortality, and disease burden.
